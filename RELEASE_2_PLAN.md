# HarmonyDocs Release 2 implementation plan

## In progress

- Visual PDF organiser with reorder, duplicate, blank-page insertion, selected-page extraction, and selected-page deletion.
- Shared page-range controls for selective rotate, numbering, watermarking, and split ranges.
- PDF-to-image export controls for PNG/JPG, resolution, and JPG quality.
- Shared privacy notice and optional consultation CTA on tool pages.
- Batch queue integration for supported multi-file tools.

## Boundaries

Release 2 remains browser-compatible. It does not claim Office conversion, OCR, AI, permanent redaction, PDF/A, signature requests, cloud imports, automatic server deletion, accounts, or payments.
